## v0.9.3

### 수정
- 재부팅 후 Claude 로그인이 풀린 것처럼 보이던 문제 완화: 토큰 갱신을 `claude auth status` 대신 `claude -p . --no-session-persistence`로 실행해 CLI가 실제로 토큰을 갱신하도록 변경 (일부 환경에서 `auth status`는 갱신하지 않음)
- 갱신 실행 시 부모 Claude Code 세션 환경변수(`CLAUDECODE`, `CLAUDE_CODE_ENTRYPOINT`)를 제거하고 입출력을 닫으며, 타임아웃을 30초로 조정

### 설치 · 업데이트
- 설정 탭의 "업데이트 확인" → [다운로드]로 자동 교체됩니다. 0.8.0 이하는 zip을 받아 한 번 직접 교체해야 합니다.
- 무결성: `SHA256SUMS.txt`의 해시와 대조할 수 있습니다.
