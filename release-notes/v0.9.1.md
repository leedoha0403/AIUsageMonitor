## v0.9.1

### 수정
- 주간(월간) 사용량을 다 쓴 경우 상태 표시가 틀리던 문제 수정: 5시간 창이 0%여도 주간이 100%면 "100% 남음"으로 나오던 것을 "0% 남음"으로 표시하고, 진행 막대·칩·알림 임계값·리셋 카운트다운도 주간 기준으로 표시
- 남은 시간이 하루 이상이면 미니 위젯(독)과 작업표시줄 칩에 `3d 03:35`(3일 3시간 35분) 형식으로 표시

### 내부 변경
- 단일 프로젝트를 Core / Presentation / 앱 셸로 분리하고, ModuleDock 호환 위젯 어댑터와 위젯 소유권 이양(핸드오프), 테스트 프로젝트를 추가 (사용자에게 보이는 동작 변화 없음)
