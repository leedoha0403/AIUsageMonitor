## v0.9.2

### 수정
- Claude 사용량 조회가 429(요청 과다)로 거절될 때 로그인 만료/오류로 오인하지 않고, `Retry-After`(없으면 5분, 최대 30분)만큼 기다렸다가 재시도하며 안내 문구를 표시
- 위젯 기본 크기를 계정 2개 기준으로 조정하고, 상세 보기를 메인 창과 같은 대시보드 크기(1100x760)로 표시

### 내부 변경
- 작업표시줄 칩 창과 대시보드 헤더를 공용 Presentation 계층(`UsageChipsWindow`, `UsageDashboardHeader`)으로 이동하고, 위젯 도킹 도착 처리·호스트 테마 연동 추가
- 미사용 위젯 모드(Compact/Normal/Detailed)·칩 위치/투명도 설정 정리, 테스트 추가(칩 크기, 요청 제한)

### 설치 · 업데이트
- 설정 탭의 "업데이트 확인" → [다운로드]로 자동 교체됩니다. 0.8.0 이하는 zip을 받아 한 번 직접 교체해야 합니다.
- 무결성: `SHA256SUMS.txt`의 해시와 대조할 수 있습니다.
